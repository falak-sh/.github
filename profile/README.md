<h3 align="center">Falak — self-hosted deployments, servers and observability</h3>

<p align="center">
An open-source replacement for Forge + Envoyer + Nightwatch, running on your own servers.<br>
<a href="https://falak.sh">Website</a> · <a href="https://falak.sh/docs">Docs</a> · <a href="https://github.com/falak-sh/falak">Source</a> · <a href="https://github.com/falak-sh/falak/discussions">Discussions</a>
</p>

---

- **Servers:** provision Ubuntu/Debian boxes with one command — firewall, SSH hardening, PHP/Node/Bun, databases, Redis.
- **Deploys:** zero-downtime, multi-server releases from git, `falak.yaml` config as code, rollbacks.
- **Apps:** sites, Cloud Functions, Docker Compose apps and 40+ one-click templates.
- **Observability:** metrics, logs, traces and APM (Laravel, Node) on a built-in LGTM stack.
- **Network:** Cloudflare DNS, Tailscale-only sites, consoles in the browser.

```bash
curl -fsSL https://falak.sh/install.sh | sudo bash -s -- --domain falak.example.com --email you@example.com
```
