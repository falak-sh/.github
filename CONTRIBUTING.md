# Contributing

Thanks for helping! Bug reports, docs fixes and pull requests are all welcome.

1. **Discuss first** for anything bigger than a small fix: open an issue or a
   [Discussion](https://github.com/falak-sh/falak/discussions) so we agree on the approach.
2. **Run it locally** with the simulation in the repo's README (`cd sim && make up`).
3. **Keep PRs focused** — one change per PR, with tests (Pest for the control plane, `go test` for the agent).
4. **CI must pass** before review. Commits are squash-merged.

Look for issues labelled `good first issue` or `help wanted` to get started.
